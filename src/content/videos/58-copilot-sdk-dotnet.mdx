## Overview
Learn how to build agentic applications with the GitHub Copilot SDK for .NET without implementing the agent loop yourself. This session covers:
- Creating and configuring Copilot SDK sessions
- Multi-turn conversations and streaming responses
- Tool orchestration and function calling
- Connecting external capabilities through MCP servers
- Agent behavior control with hooks and permission handlers
- Real-world demo: Building a Curator Agent for museum exhibits
